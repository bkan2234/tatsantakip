JSON Yedekleme / Geri Yükleme

Tüm program verilerini tek JSON dosyası olarak indirir veya JSON dosyasından geri yükler.
İçerik: Firmalar, ürünler, kategoriler, siparişler, teklifler, numuneler, ziyaret/materyal, randevular, tahsilatlar, ayarlar ve menü sırası.

Yükleme yapmadan önce mevcut veriler değişir. Önce JSON yedeği alman önerilir.

Henüz işlem yapılmadı.



Bulut Kayıt / Google Drive

Local kayıt bozulmadan Google Sheets bulut yedeği alır ve geri yükler.
Çalışma mantığı: Program önce local kayıt yapar. Bağlantı varsa veriyi Google Sheets buluta parça parça gönderir. Bağlantı yoksa local veri kaybolmaz.
Son değişiklikten sonra bekleme süresi (10–3600 sn).
Henüz bağlantı kurulmadı.

ZIP içindeki Google_Apps_Script_Code.gs dosyasını Apps Script Code.gs içine komple yapıştırıp dağıtım linkini buraya yaz.

Excel ile Ürün Ekle / Güncelle

Ürün kodu aynıysa günceller, ürün kodu yoksa yeni ürün ekler.
Kolonlar: Ürün Kodu, Ürün Adı, Kategori, Birim, Koli İçi, Liste Fiyatı, Adet Fiyat, Kg Fiyat, Durum, İskonto Yok, Not

CSV/TXT doğrudan okunur. XLSX için tarayıcı internet erişimiyle Excel okuma kütüphanesini kullanır.

Henüz aktarım yapılmadı.
